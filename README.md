# Experiment 2: NumPy Operations and Array Manipulations

## Aim

To work with NumPy arrays and perform various **NumPy operations and array manipulations**.

## Objective

The objective of this experiment is to understand the fundamental operations performed on NumPy arrays and explore their applications in numerical data processing.

* One-dimensional arrays
* Two-dimensional arrays

* Array of ones
* Array indexing

* Scalar operations

## NumPy Operations Explored

### 1. Array Creation

Different types of NumPy arrays are created, including:

* 0D arrays
* 1D arrays
* 2D arrays
* Arrays initialized with ones

### 2. Indexing and Slicing

Array elements are accessed using indexes, and specific portions of arrays are extracted using slicing operations.

### 3. Arithmetic Operations

Element-wise operations are performed between NumPy arrays:

* Addition
* Subtraction
* Multiplication
* Division
* Scalar multiplication

### 4. Aggregation Operations

Statistical and mathematical operations are performed using:

* Sum
* Mean
* Standard deviation

### 5. Boolean Masking

Boolean conditions are used to select specific elements from an array.

For example, elements greater than a specified value can be extracted.

### 6. Fancy Indexing

Multiple elements can be selected from an array using a list of indexes.

### 7. Array Reshaping

A one-dimensional array is converted into a different dimensional structure using the `reshape()` operation.

### 8. Structured Arrays

NumPy structured arrays are used to store different types of data together, such as:

* Age
* Score
